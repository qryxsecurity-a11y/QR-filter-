QR Filter

QR Filter is a modern multi-platform cybersecurity and QR intelligence platform designed to analyze, filter, generate, and monitor QR codes, links, files, and digital threats in real time.

The project combines:

A responsive web application

Native-like mobile support using Capacitor

Desktop support using Tauri

A full Express backend

Advanced analytics and monitoring

AI-powered threat analysis through QRYX AI

Sandbox and secure scanning systems

Community-driven threat intelligence
